# anore для BILLmanager 6

Платёжный модуль создаёт инвойс через API anore, переводит клиента на платёжную форму и автоматически зачисляет оплату в BILLmanager после подписанного webhook.

## Возможности

- RUB- и USD-инвойсы;
- выбор конкретного магазина и методов оплаты;
- подпись исходящих API-запросов;
- проверка подписи, суммы, валюты, `orderId` и UUID входящего webhook;
- защита от повторного создания инвойса при обновлении страницы;
- идемпотентное зачисление средствами BILLmanager.

## Требования

- BILLmanager 6 в `/usr/local/mgr5`;
- PHP 7.4+ CLI с расширениями cURL, JSON и SimpleXML;
- публичный HTTPS-домен BILLmanager;
- API-ключ anore;
- настроенный webhook магазина anore.

## Установка

Склонируйте модуль на сервер BILLmanager и выполните:

```bash
git clone https://github.com/roditsya/billmanager6-module.git
cd billmanager6-module
chmod 700 install.sh
sudo ./install.sh
```

После установки откройте `Интеграция → Платёжные системы`, добавьте `anore` и заполните:

- `Адрес API`: `https://api.anore.cc`;
- `API-ключ`: ключ магазина или аккаунта;
- `Секрет API`: секрет `X-ZPay-Signature`, если он включён;
- `Секрет вебхука`: отдельный случайный секрет;
- `ID магазина`: только для ключа уровня аккаунта;
- `Методы оплаты`: необязательно, например `sbp,yoomoney,crypto`.

## Webhook

В настройках того же магазина anore укажите:

```text
https://ВАШ-ДОМЕН-BILLMANAGER/mancgi/anoreresult.php
```

Секрет webhook в anore и в платёжном методе BILLmanager должен совпадать. Модуль обрабатывает события `payment.succeeded` и `payment.expired`, подпись берётся из заголовка `Anore-Signature`.

## Защита от дублей

Сопоставления хранятся в `/usr/local/mgr5/var/anore-payments`. Повторное открытие одного платежа возвращает уже созданную ссылку и не отправляет новый запрос в API.

Если соединение оборвалось во время создания и результат нельзя определить, модуль намеренно блокирует автоматический повтор. После проверки платежей в панели anore сбросить только конкретную попытку можно так:

```bash
sudo rm -f /usr/local/mgr5/var/anore-payments/ID-ПЛАТЕЖА.json
```

Не удаляйте файл, если инвойс уже появился в anore.

## Удаление

```bash
sudo ./uninstall.sh
```

История сопоставлений при удалении сохраняется.
